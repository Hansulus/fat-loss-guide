Abnehm Leitfaden

Ein interaktiver Leitfaden zur nachhaltigen Gewichtsabnahme.

Motivation
Diesen Projekt entstand nachdem mich Arbeitskollegen gefragt
haben, wie ich es geschafft habe in relativ wenig Zeit bereits
einiges an Gewicht zu verlieren.
Aus einem ursprünglichen Dokument für besagte Kollegen entwickelte
sich die Idee einer interaktiven Website.
Diese soll grundlegendes Ernährungswissen verständlich vermitteln 
und praktische Werkzeuge zur Verfügung stellen.

Ziele
- Grundlagen der Gewichtsabnahme vermitteln
- nachhaltige Gewohnheiten fördern
- Kalorien- und Proteinbedarf berechnen
- wissenschaftliche Erkenntnisse praxisnah vermitteln

Features
- Einführung in Kalorienbilanz und Kaloriendefizit
- Informationen zu Protein, Ballaststoffen und Sättigung
- Grundlagen zu Bewegung und Krafttraining
- TDEE-Rechner
- Protein-Rechner

Technologien
- HTML
- CSS
- JavaScript
- GitHub Pages

Lokale Nutzung
Repository klonen und index.html im Browser öffnen.
www.hansulus.github.io/fat-loss-guide aufrufen.
